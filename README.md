# Titel Dokumentation Lars Schlünzen und David Walder 
Mit unserer Webseite wollten wir die Leidenschaft des Wanderns und des Vogel-Spottings kombinieren. Über die interaktive Schweizer Karte kann der User einen Lebensraum auswählen (Berglandschaften, Wälder & Wiesen und Seen & Gewässer), woraufhin ihm alle Vögel angezeigt werden, die in diesem Lebensraum zu Hause sind. Mit einem weiteren Klick auf einen Button, wird der gewünschte Vogel in der Wanderliste gespeichert. 
# Titel Herausforderungen
Die grösste Herausforderung war es, den Überblick bei kleinsten Veränderungen im Code zu behalten. Sobald wir eine neue Webseiten-Funktion einbauen wollten, wirkte sich dies oft auf den gesamten Code aus. Zudem hatten wir zwei Tage vor Abgabe einen Herzkasper. Auf der Zielgeraden mussten wir feststellen, dass eine der beiden APIs Probleme aufwies. Glücklicherweise ging alles einen Tag später wieder. Manchmal gilt es einen kühlen Kopf zu bewahren. Während des gesamten Projekts kamen wir oft an Punkten vorbei, wo wir Entscheidungen treffen und Kompromisse eingehen mussten, die sich auf das finale Projekt auswirkten. Ein Beispiel dazu: die ursprünglichen 10 Lebensräume wurden auf 3 heruntergebrochen. 
# Titel Lottie Files Animationen
Zu Beginn hatten wir Startschwierigkeiten mit Lottie Files. Das Erstellen der Animationen im Figma gestaltete sich sehr schwierig, wobei das Exportieren mühsamer war. Die im Figma verwendeten Animationen erwiesen sich in der Praxis als störend, weshalb wir sie durch eine bestehende ersetzt haben. Diese findet man in der Wanderliste.
